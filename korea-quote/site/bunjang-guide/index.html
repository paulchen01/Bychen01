1. 先確認你貼的是哪一件商品

Bunjang 的商品連結通常帶有商品識別資訊。廢廢豬解析時會盡量核對同一商品，而不是拿搜尋結果裡相似商品的價格代替。

2. 國際版看到美元，不直接用 USD 換算

若連結落在全球版或顯示美元，報價應優先找到同一商品的韓國國內版 KRW 售價。找不到能可靠核對的韓國原始商品時，不應用美元價格硬換成韓幣後自動報價。

3. 運費與平台費可能沒有完整顯示

商品頁能確認的韓國境內運費與平台手續費才會納入。若尚未標示，廢廢豬會先以已知金額產生初步估價，並明確標示「未計入」。

4. 核對商品的最新狀態

庫存、商品狀況與是否已售出都可能快速改變。估價能協助掌握預算；購買前可回到原商品頁核對最新狀態。

常見問題

Bunjang 國際版美元價格可以直接換算嗎？

不建議。廢廢豬的策略是優先核對同一商品的韓國國內版 KRW 售價，而不是把全球版 USD 價格直接做外匯轉換。

沒有顯示韓國境內運費是不是不能報價？

仍可以做商品價格的初步估算，但會標示運費未計入，正式下單前再確認。

Bunjang 商品為什麼有時無法自動估價？

二手或單件商品可能已售出，或未公開標價與配送條件。缺少可靠售價時，系統會標示原因；可在取得韓幣金額後手動試算。
